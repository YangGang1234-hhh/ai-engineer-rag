# RAG 生成质量基线评测报告

## 评测范围与配置

- 样本：`datasets/eval/answer_eval_cases.json` 中全部 30 条人工黄金样本。
- 检索：混合检索、候选数 5、关闭 Query Rewrite。
- 模型：本地 `bge-small-zh-v1.5` Embedding、本地 `bge-reranker-v2-m3`（batch size 4）。
- 生成与裁判：`qwen-plus`；生成温度为 0，生成服务最多重试 2 次。
- 指标：LLM 裁判分别给出 1–5 分的回答相关性和证据忠实度，并统计无证据结论与无效引用。

## 总体结果

| 指标 | 结果 |
| --- | ---: |
| 完成样本数 | 30 / 30 |
| 平均相关性 | 4.2667 / 5 |
| 平均忠实度 | 5.0000 / 5 |
| 相关性满分率 | 43.33% |
| 忠实度满分率 | 100% |
| 无证据结论 | 0 |
| 无效引用 | 0 |

结论：当前生成策略具备很强的证据约束能力，未发现事实性结论脱离检索证据的情况。主要优化方向是复杂问题的**要点覆盖度**，而非抑制幻觉。

## 后续实验

1. 对低相关性样本将 `candidate_limit` 从 5 提升到 20，比较 Recall 与生成相关性变化。
2. 重新启用 Query Rewrite，并将查询改写与答案生成的模型/重试策略单独记录，评估其收益和延迟。
3. 对 2–3 分样本检查 chunk 边界、证据粒度与父子块扩展是否截断关键步骤。
4. 将本基线与优化后的同一黄金集报告并列，展示可量化的优化过程。
